# ETL_GCP_Kafka_Airflow_AWS

## Description

The aim of this project is to simulate the ETL pipeline of data flow from GCP to AWS.

The technologies will be used:

- Terraform
- Airflow
- Bigquery
- GCP Compute Engine
- Kafka
- AWS S3
- AWS Athena
